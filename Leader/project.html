How the workflow works

1
Admin creates project

Set name, description and required skills/languages.

2
Members select skills

Members update their skill profile so leader can match them.

3
Leader assigns tasks

Tasks are created with deadlines & assigned to skill-matched members.

4
Submit & Review

Member submits work; leader approves or requests changes with reason.
